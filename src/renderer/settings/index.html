Bienvenue

Desk Assistant écoute le son de ton PC (appel, visio, vidéo), le transcrit et te propose quoi répondre dans une petite fenêtre. Trois étapes suffisent pour démarrer.

  1. Ajoute tes deux clés API Une pour la transcription (ElevenLabs), une pour les réponses (Claude).
    Ouvrir
  2. Vérifie que le son arrive Lance une vidéo : une barre doit bouger dans le Diagnostic.
    Tester
  3. Dis à l'assistant ce que tu fais Entretien, réunion, cours… et quelques lignes sur toi.
    Préciser

Une nouvelle version est prête à être installée depuis l'appli.

Documents de travail

Un projet de code, des cours, des textes de loi, des PDF… L'assistant les consulte pour répondre à des questions précises comme « pourquoi as-tu écrit cette fonction comme ça ? ». Tout est lu sur ce PC.

  1. Choisis ou crée une base

  2. Ajoute des fichiers

    Un dossier de projet entier ou des fichiers : code, PDF, Word, PowerPoint, texte… Les dossiers inutiles (node_modules, .git…) sont ignorés.

    Si c'est ton projet, dis-le : l'assistant répondra à la première personne.

  3. Laisse Claude comprendre le contenu

    Une note par fichier (rôle, éléments, choix), puis une fiche de synthèse. Le coût en tokens est affiché avant de lancer.

    Fichiers de la base

    Clique sur un nom pour lire la note écrite par Claude.
